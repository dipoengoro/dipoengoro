### 🏠 The homelab habit

Everything below runs on a VPS I administer, reachable only through a private tailnet:

- **Proxy &amp; access** — Caddy reverse proxy in front, Authelia + LLDAP for single sign-on
- **Services** — Nextcloud (files &amp; photos), Vaultwarden (passwords), Memos, Trilium, Vikunja
- **Observability** — Prometheus + Grafana + Loki, node exporters on every machine, alerts that stay silent while everything is healthy
- **Backups** — restic to Hetzner object storage with a second mirror, restore tested, not assumed
- **Automation** — cron jobs and collectors writing into Postgres, reporting only when something actually breaks
